# 攻撃・守備表示の判断（2026-11-08）

攻撃しないと分かる場面で、攻撃力と守備力を比較して特殊召喚時の表示形式を選ぶ補助を追加しました。高い方を使い、同値なら守備表示を基本にします。トラックメイカーはATK 0／DEF 2500なので守備表示、クリスタルウィングはATK 3000／DEF 2500なので攻撃表示を選びます。

自動で比較するのは先攻1ターン目、相手ターン、バトル後のメイン2・エンドなどです。後の自分メイン1・バトル中は、攻撃予定が未確定なら元のモデルの判断を維持します。読み込んだポリシーの set_attack_intent(False) で「攻撃しない」、True で「攻撃する」を明示でき、None で自動判定に戻せます。攻撃予定の指定を教師の評価目標から自動注入する仕組みではありません。

合法な表示形式の候補だけから選びます。通常召喚の攻撃表示、効果で守備表示が指定された特殊召喚などを強制変更しません。裏側の選択も維持します。表示形式が効果に関わる未対応カードは元の判断を残し、ストリチアの中央での攻撃力や、公開の相手チューナーによるリミックス等の攻撃力上昇は反映しています。場に出る前の比較には公開の基礎値と対応済みの効果を使っており、あらゆる対戦状態の将来の攻守を予測するものではありません。

前回の中央配置の比較で使った44初手を同じ重みで再比較し、表示形式の修正前44/44、修正後44/44で展開成立を維持しました。表示選択を100回変更し、トラックメイカーは30回すべて守備表示になりました。選択応答だけでなく、実際に場へ出た30体の守備表示も確認しています。手本26分岐は26/26成立、Luaエラー0です。この44初手は今回初めての未使用評価セットではありません。

攻撃予定を明示した時の攻撃表示、攻撃しない時の守備表示、同値、強制された表示形式、リミックスの公開チューナーによる強化なども確認しました。相手墓地にうららがある制御した盤面では、エンジンが返すリミックスのATK 3000／DEF 2000を確認し、攻撃表示を選びました。この効果確認は44初手の展開成績とは別の検査です。

今回は前回の中央配置補助に表示形式の補助と手本の修正を重ねたもので、ニューラルネットの重みの再学習は行っていません。元の重み・デッキ・カード処理・前回の評価記録は保持しています。新しいリプレイのサーバー保存は0件です。

利用入口は scripts/verified_opening_policy.py の create_policy() です。config/latest-verified-opening-policy.json の battle_position_adapter に今回の設定を記録しています。既存の継続自己対戦プログラムそのものへの組み込みは行っていません。
