## 2. B2Bへ進む共通の手順（R0〜R3・A1で使用）：**合法に成立した**

相手のドローフェイズ（段72）に、次のように進んだ。
1. リミックス②を発動し、墓地のうららとレコを選んだ。
2. レコを手札へ戻し、うららを特殊召喚した。
3. 続けて「S召喚を行う」を選んだ。
4. **B2Bが場に出た。** S召喚するモンスターと素材（うらら＋ザレン）の選択画面は出なかった（候補が1つずつで、envが自動で決めた）。

| 確認 | 結果 |
| --- | --- |
| 場（前 → 後） | ザレン＋リミックス → **B2B** |
| 手札 | ＋レコ |
| 墓地 | ＋リミックス（コスト）、＋ザレン（素材）。うららは素材として墓地へ戻った |
| B2B①：相手モンスターのレベル | B2Bがいる条件では、ルキナは**レベル8**だった（B2Bがいない A0 ではレベル6） |

## 3. 回収・展開の4条件（R0〜R3）

いずれも相手がルキナのサーチを発動した時点（段94、チェーン1）で行った。この時点で、B2B③（説明番号0）は合法な行動に出ていた。

| | R0 使わない | R1 手札へ回収 | R2 特殊召喚のみ | R3 特殊召喚から追加S召喚 |
| --- | --- | --- | --- | --- |
| B2B③の発動 | なし（パス） | チェーン2で発動 | 同左 | 同左 |
| 対象の候補（墓地の、レベル10以外のチューナー） | — | うらら・ザレン・リミックス・トラックメイカー・キュー・ミクス・ロタリー | 同左 | 同左 |
| 選んだ対象 | — | キュー | キュー | キュー |
| 選択肢（手札へ1190／特殊召喚1152） | — | 両方提示 → 手札へ | 両方提示 → 特殊召喚 | 両方提示 → 特殊召喚 |
| 追加S召喚の確認 | — | **出ない**（S召喚できるモンスターがないため） | 出た → しない | 出た → する |
| S召喚 | — | — | — | 候補はラウドネスウォーとトラックメイカー → **トラックメイカーが実際にS召喚された**。素材は場のキュー（自動）＋**手札のヴェーラー1枚**（選択画面で選んだ） |
| 自分の変化（チェーン解決後） | — | キュー：墓地 → 手札 | キュー：墓地 → 場 | 場にトラックメイカーが出た。キューとヴェーラーは墓地へ（手札−ヴェーラー） |
| チェーン終了後に新たに発動できた効果 | — | ヴェーラー×3、シンクロ | ヴェーラー×3、シンクロ | **キュー②（墓地）とトラックメイカー①**（いずれもパス） |
| 相手のサーチ | 通った | 通った | 通った | 通った |
| 再現確認 | 111/111段が一致 | 114/114 | 117/117 | 122/122 |

- B2B③は回収・特殊召喚・S展開の効果で、サーチを止める効果ではない。4条件とも、相手の手札には獄神精が加わった。
- R3では、キューの「手札のチューナーもS素材にできる」という処理が、実際の素材の選択（場のキュー＋手札のヴェーラー）として成立した。

## 4. 攻撃の2条件（A0・A1）

攻撃役はザレン。ほかのモンスターには攻撃させていない。

| | A0：B2Bなし | A1：B2Bあり（B2B③でザレンを特殊召喚） |
| --- | --- | --- |
| 局面の作り方 | P1のザレンをそのまま残した。相手ターンは何もしない | 共通手順でB2Bへ進んだ後、ルキナのサーチに対してB2B③で墓地のザレンを特殊召喚した（追加S召喚の確認は出なかった） |
| 第3ターン開始時の自分の場 | ザレン（攻撃表示）、リミックス（守備表示） | B2B、ザレン（ともに攻撃表示） |
| 相手の場 | ルキナ（攻撃表示、レベル6） | ルキナ（攻撃表示、**レベル8**） |
| 1回目の攻撃 | ザレンがルキナを攻撃し、ルキナは破壊された。相手LP 8000 → **7700** | 同じ。相手LP 8000 → **7700** |
| 2回目の攻撃 | ザレンの攻撃は**選択肢に出なかった** | ザレンの**直接攻撃が選択肢に出て、実行した**。相手LP 7700 → **4900** |
| その後 | — | ザレンの攻撃は出なかった（2回まで）。B2B自身の直接攻撃は出ていたが、使っていない |
| 再現確認 | 114/114段が一致 | 138/138 |

- LPは、snapshotの値で記録した。攻撃力から計算した値ではない。
- **A0とA1で違う点：** 自分の場（リミックスかB2Bか）、自分の手札（A1ではレコが増えている）、ルキナのレベル（6か8か）。
- この比較で確認したのは、追加攻撃の働きである。B2Bへ進む方が常に強いことを示すものではない。
