# 獄神精を含む2枚初動・うらら回収の追加（2026-11-08）

採用済み40枚＋EX15枚のまま、依頼された初動と回収パターンを追加しました。各パターンは指定2枚＋使わない3枚で、手札の並び・残りデッキ順・使わない3枚を変えた3条件ずつ再現しています。15/15で先攻の盤面へ到達し、うららを呼ぶ4パターンは12/12で相手ドローフェイズの回収と、その後のサーチへの使用まで確認しました。Luaエラー0です。手順によるルールエンジンでの再現で、学習済みAIの成績や実クライアントでの試験ではありません。

獄神精を含む2ルートは、最初のトラックメイカーに手札の獄神精を使い、その墓地効果からエルフェンノーツ側へつなぎます。後から獄神精を蘇生してレギナのレベルを上げ、バロネスを出してからキュー／ジュークジョイントの制約を受ける順です。今回の盤面にはクリスタルウィングは含めていません。

キュー＋獄神精では、最初にキュー①を使って制約を受けてしまうと、その後エルフェンノーツの非チューナーを特殊召喚できません。最初は①を見送り、獄神精を手札からS素材にし、後半に墓地のキューをミクスで回収してジュークジョイントの追加召喚を使います。この順序を別の参照手順として登録しました。[キューの公式Q&A](https://www.db.yugioh-card.com/yugiohdb/faq_search.action?cid=21956&ope=4&request_locale=ja)

うらら回収は、キューで特殊召喚したうららをS素材にして墓地へ置き、相手ドローフェイズにリミックスをリリースして、うららを手札・もう1体を場へ戻します。リミックスが戻せるのはSモンスター以外のチューナー2体で、キラーチューン以外のうららも含められます。[リミックスの公式テキスト](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=21958&ope=2&request_locale=ja)

回収後は、相手がメインフェイズにルキナを特殊召喚してサーチ効果を発動する試験を行い、回収したうららを手札から発動してサーチが増えないことを確認しました。うらら回収前に発動済みのサーチへ、回収後からさかのぼってうららを使えるという意味ではありません。相手の妨害でリミックス等を止められた場合は今回の範囲外です。

相手ターンのリミックスによる即時S召喚は、この回収試験では見送っています。B2Bへ伸ばすことや相手の全展開への応答も、ここで確認した到達目標には含めていません。現在の5つは参照例であり、全ての複数枚の持ち方・最善のプレイを網羅するものではありません。

通常召喚回数は記録するだけで採点しません。2枚初動であることの確認として、指定以外の初手3枚を使っていないことも別に検査しています。レシピ・元のモデル・評価器は変更せず、今回の5パターンでのAI学習は未実施です。新しいリプレイのサーバー保存は0件です。
