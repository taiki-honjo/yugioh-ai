# Claudeへの依頼：B2Bの回収・展開・攻撃を確認する有限試験

2026-11-09（日本時間）。設計・依頼文。今回の資料作成では、実エンジンの実行・学習・対戦・本番変更を行っていない。

## 1. 目的と範囲

ザレンの4条件は、ユーザー報告で合法な手順として実行・再現され、相手サーチへの作用と追加の破壊を分けて記録できた。

次はキラーチューンB2B（カードID 65961304）の機能を、小さな試験で確認する。自分のターン終了時のカード名や、直接無効の回数だけで価値を決めず、資源の移動・相手ターンの展開・攻撃を別々に記録する。

**新しい実験root・台帳で、6条件を1回ずつ＋各1回の再現、計最大12回。** 既存3領域の台帳・上限は変更しない。実エンジンを起動する準備実行やテストも、この12回へ含める。勝手に追加試行・総当たりへ広げない。

## 2. 確認したカード処理

現在のデッキにはB2B、ザレン、トラックメイカーが入っている。B2Bのローカルスクリプトは、対象のチューナーを手札へ戻す／特殊召喚する分岐、その後の任意のS召喚、チューナーへの追加攻撃を実装している。

公式テキストも確認済み：[キラーチューン B２B](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=22551&ope=2&request_locale=ja)。ただし、今回の局面で各選択が合法にできることは、まだエンジンで確認していない。

## 3. B2Bへ進む共通の手順候補

既存P1のtrain初手と手本を使い、自分のターン終了時のザレン＋リミックスまでを再現する。

相手ドローフェイズで、次の手順を候補にする。

1. リミックスで、墓地のうららとレコを選ぶ。
2. レコを手札へ戻し、うららを特殊召喚する。
3. ザレン（レベル7、S素材時は非チューナーとして扱える）とうらら（レベル3）で、B2B（レベル10）へ進む。

これはカード処理から組んだ**手順候補**であり、成功を確認済みとはしない。対象の所在、S素材の条件、使用可能な効果、制約を本実行の合法選択肢で確認する。実現できない場合は理由と未確認を残し、カード処理を変更して通さない。

手順確認を独立した追加実行にせず、条件の本実行に含める。自分のターン・相手ドローフェイズ・相手メインフェイズを区別して記録する。

## 4. 回収・展開の4条件

相手がルキナのサーチを発動する場面を使う。試験対象以外の応答はパスし、B2Bを使わない対照も置く。

| 条件 | B2Bで行うこと | 主に確認するもの |
| --- | --- | --- |
| R0 | 効果を使わない | 相手サーチと資源の基準 |
| R1 | 合法な対象を手札へ戻す。追加S召喚はしない | 墓地／除外から手札への移動 |
| R2 | 合法な対象を特殊召喚する。追加S召喚はしない | 召喚したカードと、場・資源の変化 |
| R3 | 特殊召喚し、合法な追加S召喚まで行う | 素材、到達先、タイミング、残る資源 |

できるだけ同じ対象をR1～R3で使う。候補は墓地のキュー（レベル3）。R3でキューと手札ヴェーラー（レベル1）からトラックメイカーへ進めるかを、キューの手札素材の扱いを含めて確認する。

この対象と到達先も未検証の候補。合法に作れなければ条件付き／未確認とし、別の対象へ置き換える場合は、変更理由・比較条件の差を記録する。自分の結果に都合のよい探索を無制限に行わない。

各条件で記録するもの：

- B2Bを発動できた状況と対象候補、実際に選んだ対象・選択肢。
- 対象が手札へ入ったか、場へ出たか、S素材になったか。
- 追加S召喚が、メニューに出ただけでなく実際に成立したか。
- 相手のサーチが解決したか。B2Bでカードを回収・展開しただけで、サーチを止めたとはしない。
- チェーンが終わった後に新たに発動できる効果を、そのタイミングごとに記録する。
- 手札・場・墓地・除外・EXの変化と、残るコスト・後続。
- B2B存在中の相手モンスターのレベル変化を観測できた範囲。

解決中に増えたカードを、すでに進行中の効果へ無条件で割り込ませられるとは仮定しない。未実行の効果の働きは、合法候補と実行結果を区別する。

## 5. 攻撃の2条件

同じ種類のチューナーを攻撃役とし、B2Bあり／なしで2回目の攻撃の合法性と実際の攻撃回数を比較する。

| 条件 | 状態 | 確認するもの |
| --- | --- | --- |
| A0 | B2Bなし | 同じ攻撃役の攻撃回数、2回目の候補の有無 |
| A1 | B2Bあり | 2回目の攻撃を選べるか、実際に実行できたか |

攻撃役の候補はザレン。A0はP1のザレンを残す形、A1はB2Bへ進んだ後にB2Bでザレンを蘇生し、次の自分のバトルフェイズへ進む形を候補にする。ほかの自分のモンスターには攻撃させない。

同じ攻撃役・相手の配置と表示形式・LP等を可能な範囲で揃え、異なる点を明記する。合法な手順で局面を作る。任意の盤面を直接置くnative機能があると仮定しない。

攻撃宣言だけでなく、実際の戦闘の実行・相手カードとLPへの結果を記録する。現在のsnapshotに攻撃力がないからといって、推測した固定ダメージを正解にしない。

これは追加攻撃の機能確認であり、A0とA1で盤面全体が完全に同じ、またはB2Bへ進む方が常に強いと証明する試験ではない。相手が先に敗北して2回目が不要になった場合等は、確認できた範囲として扱う。
