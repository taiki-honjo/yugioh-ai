# 増殖するG・ドロールの継続的な働き：4条件の試験

2026年11月9日（日本時間）。設計書：`docs/opening-capability-eval-v1-design-2026-11-09.md` の11.3節・11.5節。記録：`experiments/handtrap-continuing-20261109/`。

**範囲**
- 新しい実験領域で、同じ初手・seed・展開側の台本を使い、4条件を実装・実行した。
- **実エンジンの実行は8回**（4条件＋各条件の再現確認、上限8回）。この領域専用の台帳で数えた。
- 前回の能力試験の台帳（12回上限、使用6回）は変更していない。

**変えていないもの**
- 採用基準・学習報酬・本番設定・本番の状態

学習・通常の対戦・モデルの使用もしていない。

## 1. 試験の設定

| 項目 | 内容 |
| --- | --- |
| 展開側（相手） | 先攻（player 0）。train区分 `elf-rukina-regina-g00-p0`（seed 151080）の**手本の流れ**で、第1ターンを展開する（能力試験のP2と同じ流れ） |
| G・ドロールを持つ側 | 後攻（player 1）。標準の固定初手（ルキナ・うらら・ヴェーラー・ドロール・G）。条件で決めたカードだけを、**合法になった最初の時点**で発動する。それ以外はすべてパス |
| 台本が止まった場合 | 展開側の次の予定行動が選択肢に無いときは、その時点と、そのとき合法だった行動を記録する。その後、展開側は新しい行動をせずにターンを終える（**この台本の性質**であり、制限の効果とは分けて扱う） |
| 測る範囲 | 展開側の第1ターンの終わりまで |
| 判定の方法 | 「デッキから手札へ」は、手札に増えたカードのうち、その持ち主の公開領域から来たものでないもの、として数える（相手の非公開情報を、評価器だけが使う） |

G・ドロールを持つ側は、この台本で他にドロー・サーチを行わない。そのため、この側の手札がデッキから増えた分は、すべてGのドローと判定できる。

- 再現確認は4条件とも、開始と終了の状態を含めて一致した。Luaエラーはすべて0。
- 「どちらも使わない」は、能力試験で記録したP2の手本の流れと、展開側の69判断が完全に一致した。

### 2.1 Gだけ使う

- 展開側の10回の登場ごとに1枚ずつ、計10枚を引いた。引いたカード：ロタリー、レギナ×2、調和ノ天救竜、ストーン・スィーパー×2、フォルトナ、うらら×2、朔夜しぐれ。
- 展開側の行動は変わらなかった。パス以外の45行動は基準と同じで、判断数が3つ増えたのは、Gの発動に対してドローフェイズにパスした分である。
- Gのドローは継続効果で、チェーンを作らない（`c23434538.lua` で、ドローは `EFFECT_TYPE_CONTINUOUS+EFFECT_TYPE_FIELD` の処理）。そのため、展開側の判断の機会も増えなかった。

### 2.2 ドロールだけ使う

- ルキナのサーチでレギナが手札に加わった後、展開側がレギナを発動した。ドロールが初めて合法になったのはこの時点で、そこにチェーンして発動した。
- **制限の直接の効果（エンジンで確認）：** ストリチアを特殊召喚した直後、展開側に出た墓地効果の候補が、次のように変わった。
  - 基準（段28）：獄神精とレギナが出る。獄神精の効果でディーナをサーチした。
  - ドロールあり（段29）：**レギナだけ**が出て、獄神精のサーチ効果は合法な行動に出なかった。
  - ドロールの適用後、展開側がデッキから手札に加えた枚数は0だった（`c94145021.lua`：`EFFECT_CANNOT_TO_HAND` と `EFFECT_CANNOT_DRAW`）。
- **台本の性質によるもの：** その後、手本はディーナを選ぶ予定の段で止まり、規則どおりターンを終えた。
  - 止まった時点（段34）でも、ストリチアの場の効果と通常召喚は合法だった。
  - そのため、「ストリチアだけの盤面」は、ドロールの制限と、台本が止まったときの規則が合わさった結果である。**ドロールが相手の最終盤面をここまで減らした、とは言えない。**

### 2.3 両方使う（G → ドロールの順）

- Gはルキナの特殊召喚で1枚（ロタリー）を引いた。ドロールの適用後に展開側が2回特殊召喚したが、**Gのドローは0枚**だった。ドロールが自分側のGのドローも止めることを、エンジン上で確認した。
- 展開側の行動は、ドロールだけの場合と同じだった。
- 得たものは、ドローが1枚と、展開側のサーチ1回の阻止である。Gだけの10枚と、ドロールだけの制限とを足し合わせたものではない。
