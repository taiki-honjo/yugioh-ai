## 3. 学習画面と追加する損失

元の4画面とキャッシュの出所は、coverageと同じ。
`/home/hatk8/projects/yugioh-ai/experiments/artmage-response-coverage-20261111/code/cv_train.py`

- S1：ディアクトロス②へのCE。
- S2：ファインメルト③へのCE。
- M：元モデルの獄神獣②を第一候補とする分布へのKL。
- P：元モデルのパスを第一候補とする分布へのKL。

元モデルは固定base＋headだけ。coverage候補の補正後の分布を参照にしない。cacheの各値と元記録のstep・NPZの添字・合法手を照合する。

今回の目的関数：

```text
loss = mean(CE_S1, CE_S2)
     + 1.0 * mean(KL_M, KL_P)
     + 1.0 * relative_retention

relative_retention = mean_over_screens(
    mean_over_protected_actions((delta(action) - delta(pass)) ** 2)
)
```

`delta` は新しい追加部分の出力。固定元モデルには追加部分がないので、守る相対補正の目標は0である。これは、補正後と元の「action対passのlogit差」のずれに等しい。

保持する候補のマスク：

| 画面 | 相対得点を直接保持する候補 |
| --- | --- |
| S1 | 合法な候補からパスと、教えるディアクトロス②だけを除く |
| S2 | 合法な候補からパスと、教えるファインメルト③だけを除く |
| M・P | 合法な候補からパスだけを除く |

パスのindexは元snapshotのact=CancelとNPZから照合して保存する。カードID=0だけで推測しない。今回教える正例と同一の意味の重複候補がある場合は、正例を保持側で相反して押さないように照合する。違法手・パディングを分母へ入れない。

このマスクにGを特別扱いするルールは入れない。Gは「今回の正解として教えていない合法候補」の1つとして対象になる。MでGが合法でない場合、存在するものとして追加しない。

生のパスの補正が負でも、他の未指定候補に同じ補正が加わるなら、相対評価は変わらない。生のパス補正を0にすることや、全補正の絶対値を小さくすることを今回の達成条件にはしない。
