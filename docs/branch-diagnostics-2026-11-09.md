## 3. 観測できたこと

1. 2ケースとも、最初に操作が分かれたのは、自分のターン1のメインフェイズ・チェーンなしの行動選択で、2つの行動の順番の選択だった（フォルトナの効果かキューの通常召喚か／キューの通常召喚かジュークジョイントか）。配置・表示形式の補助は、分岐に関与していない。
2. **採用モデル自身が、その分岐点でほぼ五分五分だった**（差0.21と0.42、確率0.55と0.60）。C・Dの重みの変化は小さい（baseの相対L2が約5×10⁻⁴）が、この差を逆転させるには足りた。分岐点での候補の差は0.003〜1.67と幅がある。
3. 分岐点で採用モデルが選んだ操作は、教師の手本と同じ順だった。失敗候補は、手本の順から外れた最初の位置で失敗の経路に入った。
4. 分岐後、mixed-rukina-cueでは、トラックメイカーの素材に獄神精を使い、バロネスが合法手にならないまま終わった。JJでは、ジュークジョイントがうららのいない状態で使われ、その後もうららを場に出さなかった。どちらも、最初の分岐の後に、大きなlogit差で決まった判断が続いている。
5. 失敗の中身は2ケースで違う。mixed-rukina-cueは盤面の1要素（バロネス）の欠落。JJは、盤面は受け入れる終盤に届いたが、妨害とその回収の条件（解放・回収・無効化）の欠落。
6. 成功した候補のうち、C-777のJJケースでは、ニューラル方策の配置の選択が採用モデルと違ったが、補助の置き直しで実際の操作は同一になった。

## 4. まだ分からないこと

- 分岐点の1手だけで失敗が決まるのか（分岐後の局面から目標へ合法に届く経路が残っていたか）。
  - mixed-rukina-cue：キューを先に通常召喚した後で、バロネスが合法手にならなかった理由（レベル・素材の条件など）を、ルールの上で確かめていない。
  - JJ：ジュークジョイントを先に使った後で、解放が同じターン内に可能だったかを確かめていない。
- 採用モデルが候補と同じ分岐後の局面に置かれたら、同じ後続の判断をするのか（採用モデルはその局面を一度も通っていない）。
- この「ほぼ五分五分の順番の判断」が、他の成功ケースにどれだけあるか。今回の2ケース以外は調べていない。
- 自己対戦の更新が、なぜこの2つの判断の向きを変えたのか。学習中の勾配と、この局面の関係は記録していない。

最初の相違は、失敗に至る経路の入口であることは確認できた。しかし、それを唯一の原因とは断定しない。
