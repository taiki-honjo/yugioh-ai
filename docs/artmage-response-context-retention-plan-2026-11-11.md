## 3. 保持するものを正しく定義する

新しい応答2系列の対象画面より前で、**開始モデル自身の合法手の確率分布**を固定して保存し、学習後の分布がそこから大きく動かないようにする。参照はbaseとheadを合わせた最終logitsから作る。

**記録された実行手をそのまま「元モデルの選択」としてラベルにしない。** S2の履歴には、元モデルが改変を選んでいたのに、実験側が襲撃をセットさせた画面がある。実行手へのCEを足すと、保持ではなく別の操作を新たに教えてしまう。

元の記録の操作は、その局面へ進める履歴として使う。各時点で「この履歴を与えられた開始モデルがどの分布を返すか」を別に計算して保存する。RNNは開始から同じ観測履歴で構築し、対象画面だけの入力で推論しない。

参照分布は同じGPUバックエンド・精度設定で計算し、固定配列にしてハッシュを登録する。旧報告のCPU/GPUによる境界付近の第一候補の差と、学習による変化を混ぜない。診断では同じバックエンド同士で比較し、実エンジンで使うCPUの選択は別に照合する。

## 4. 損失とマスク

元データは次のmanifestと同一の旧40＋応答2系列。元ファイル・旧マスクは上書きしない。

`/home/hatk8/projects/yugioh-ai/experiments/artmage-response-learning-20261111/data/manifest.json`

新しい応答系列でだけ、従来の対象1手のCEに、次の保持損失を加える。

```text
loss_response = CE_response + 1.0 * KL_context
KL_context = mean_over_sequences(
    mean_over_preserved_steps(
        KL(p_start_legal || p_current_legal)
    )
)
```

- 温度は1。参照分布はstop_gradientで固定する。
- 保持対象は、応答画面より前の自分の判断のうち、表示形式補助が担当するselect_positionを除き、合法手が2つ以上あるもの。
- **教え直す応答画面はKLの対象から除く。** S1で元のパスを保持しながらディアクトロス②を教える、という競合を作らない。
- 応答の直接CEは、従来どおりS1のディアクトロス②とS2のファインメルト③の各1手だけ。ターン3や他の操作へ新しいCEラベルを足さない。
- KLは合法手だけで正規化して計算し、無効な候補のlog確率からNaNが出ないようにする。パディング・単一合法手・補助担当画面は平均の分母に入れない。
- 旧データのバッチの損失は前回と同じCEだけ。新しい応答バッチでだけCE＋KLとする。
- 系列の長さで重みが増えないよう、KLは各系列の保持対象で平均してから2系列で平均する。対象CEを文脈の長さで薄めない。
- 候補のRNNは候補自身の重みで同じ観測履歴を通す。元モデルの内部状態を候補へ与えない。文脈への逆伝播は従来どおりで、今回同時にstop-gradient等を追加しない。

係数1.0はこの試行の固定値であり、最適値とみなさない。結果を見て係数を調整したり、複数係数の候補を作ったりしない。保持対象外の局面での判断を保証する方法でもない。
