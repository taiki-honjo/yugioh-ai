# 能力評価の基盤実装：記録保存・再現確認・O1の最小試験

2026年11月9日（日本時間）。依頼資料：
- `docs/claude_capability_probe_next_2026-11-09.md`
- `docs/claude_capability_addendum_zaren_b2b_g_droll_2026-11-09.md`

設計書：`docs/opening-capability-eval-v1-design-2026-11-09.md`（第11・12節を追加）

**範囲**
- 影評価の基盤（記録保存、同じ局面の再現確認、O1の最小試験）を、train区分の2件だけに実装・実行した。
- **実エンジンの実行は6回**（上限12回）。

**変えていないもの**
- 本番、旧gate、自動採用基準、学習報酬、復習データ
- 5回目の候補、`STOP`、`pending`

学習・通常の対戦・再開・候補の採用はしていない。

**範囲の限定**
- O1（ルキナのサーチ1回）は、基盤の動作を確かめる試験である。盤面全体の価値は表さない（設計書11.4）。
- どちらのケースも手本で作った局面で、モデルが自力でそこへ到達した成績ではない。

## 3. P1：うららの回収（準備）、ルキナのサーチへの応答、サーチ阻止の証拠

- **ケース：** `cue-reco-jj-zaren-g00-p0`（train）。初手はキュー・ヴェーラー×3・レコ、seed 151080。
- **自分のターン終了時：** ザレン＋リミックス（守備）、ジュークジョイント（表側）、キラーチューン・シンクロ（セット）。手札はヴェーラー×3。
- **旧合否：** 合格（JJ解放の段＝37、うららをS素材にしていない、回収したうららを発動、サーチを無効）。

| 段階 | 時点・チェーン | 内容と証拠 |
| --- | --- | --- |
| 準備 | 相手のドローフェイズ（段72）、チェーン1 | リミックス②を発動。選択はうらら・レコ。解決後、自分の手札に**うららが1枚増え**、場ではリミックスがレコに入れ替わった。サーチの発動（段92）より前の段81で解決済み |
| 相手の行動（O1） | メインフェイズ1（段92） | ルキナ②（デッキから手札へ）を発動 |
| 応答 | 段93、**チェーン2** | 手札のうららを発動 |
| 結果 | チェーンの解決後 | **相手の手札は、サーチの発動前と同じ**（増減なし）。ルキナは場に残っていた（発動元を除いて止めたのではない）。判定：`search_not_applied` |

- **能力：** この手本の局面とこの流れについて「**確認済み**」。
- **応答時点のほかの合法な候補：** ヴェーラー×3、セットしたキラーチューン・シンクロ。いずれも解決の結果は未確認。
- **ザレン②：** チェーンがルキナ② → うららになった時点で、合法な候補に出た（段95）。2つ目のチェーンという条件と合う。解決の結果は未確認。

## 5. 能力の試験とモデルの使用試験の差

**モデルの使用試験の条件**
- 使ったのは採用モデル（base `86b4358d…`、head `6ca3221f…`）と、本番と同じ配置補助v2・攻守表示補助で、GPUで実行した。
- 自分のターンは手本の行動で進め、RNNにはその間の観測を順に入れた。RNNの状態の更新は選んだ行動に依存しないので、履歴は手本の流れと同じになる。配置補助の記憶は、実際に実行した行動で更新した。
- 制約：手本の行動で進めた段の、配置の出来事（msg 11）は再現していない。
- 相手ターンからは、モデルが判断した。

| ケース | 能力の試験 | モデル |
| --- | --- | --- |
| P1 | リミックスで準備 → うららで応答 → サーチ阻止（確認済み） | **手本と同じ判断をした（96段すべて一致）。** ドローフェイズにリミックス、うららを手札に、サーチにうららを発動し、サーチは機能しなかった。分類：**使った** |
| P2 | サーチの時点で合法な候補が6つ（止められるかは未確認）。パスすればサーチは通る | ドローフェイズに**ラプソディア**を発動し、バロネスを墓地へ送って獄神精を特殊召喚した。そのため、サーチの時点ではバロネス②が使えなかった。サーチの時点では、クリスタルウィング①などが合法だったがパスし、サーチは通った。分類：**使える候補があったのに使わなかった**（それで止められたかは未確認） |

- P2の結果は、「早い時点の行動が、後の応答の資源を使ってしまう」例である。
- ただし、これは手本で作った局面1件での結果である。モデルが通常この判断をするとか、P2の盤面が弱いという結論にはならない。
