## 3. 用語の短い具体例

- **判断数（steps / timesteps）**：対戦数やターン数ではなく、「通常召喚するか」「どのカードの効果を発動するか」「どのモンスターを対象にするか」といった、モデルが1回選択を行う細かい意思決定の回数です。
- **重み（weights / パラメータ）**：モデルの中にある約434万個の調整可能な数値です。対戦ログを保存しただけでは賢くならず、学習プログラムでこの数値を更新することで行動の選び方が変わります。
- **チェックポイント（checkpoint / `.flax_model`）**：学習途中の「重み」をファイルとして保存したものです（約17.4MB）。
- **シード（seed）**：乱数の初期値（例：`seed=1000`）です。同じシードを指定すると、初期手札や山札の並び順などのランダム条件を揃えて公平に比較できます。
- **先後ペア比較（seat-swapped pairs）**：同じ乱数シード（同じ初期手札・山札順の乱数系列）に対して、評価したいモデルが「先攻（Player 0）」と「後攻（Player 1）」の両方を1戦ずつ戦い、先攻有利や初手運の偏りを打ち消して比較する方式です。

## 4. 基本コマンド（Ubuntu-22.04 内）

### 4.1 環境とファイルの整合性チェック（学習・対戦は行いません）

`/opt/ygo-ai` の仮想環境・ネイティブエンジン・デッキの改行コード・保存済み重みファイルのハッシュ（SHA256）が正常かを確認します。

```bash
cd /home/hatk8/projects/yugioh-ai
bash scripts/check-env.sh
```

### 4.2 モデルの対戦評価を実行する場合

学習に使っていないシード（デフォルト `seed=1000`）を用い、先攻・後攻を入れ替えて対戦評価を行い、**勝敗・決着理由（異常終了の有無）・判断時間**を分けて `records/` 配下に保存します。

```bash
cd /home/hatk8/projects/yugioh-ai

# 標準ベースライン評価スイート一括実行（random / 未学習init / 4096判断 / 4096+512判断 の比較）
bash scripts/eval-blueeyes.sh --suite --num-episodes 32 --seed 1000

# 個別のモデルと対戦相手を指定して評価する例（4096+512判断モデル vs 4096判断モデル）
bash scripts/eval-blueeyes.sh \
  --candidate checkpoints/trial-2026-10-27/blueeyes-4096-plus512.flax_model \
  --opponent checkpoints/trial-2026-10-27/blueeyes-4096.flax_model \
  --num-episodes 32 --seed 1000
```

### 4.3 小規模学習を新しく試す場合（※必要時のみ手動実行）

判断数は `128` の倍数で指定します。結果は `experiments/manual-日時/` に保存されます。

```bash
cd /home/hatk8/projects/yugioh-ai
bash scripts/train-blueeyes.sh 4096
```

### 4.4 保存済みの重みから追加学習する場合（※必要時のみ手動実行）

第2引数に引き継ぎたい `.flax_model` ファイルのパスを指定します。

```bash
cd /home/hatk8/projects/yugioh-ai
bash scripts/train-blueeyes.sh 4096 checkpoints/trial-2026-10-27/blueeyes-4096-plus512.flax_model
```
